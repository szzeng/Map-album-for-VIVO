# MAP-004 UI 设计规范｜图迹

> 设计基线：MAP-004 受限样本预览阶段  
> 代码基线：b876054ce6dc2e91c81aeae95eeeaa46e0f0f1b0  
> 目标设备：vivo X300 Pro / Android  
> 本文件与同目录的 MAP-004-UI-MOCKUP.svg 配套使用，是 UI 实施的唯一视觉规范。

## 1. 产品定位

图迹是一款地图优先的个人照片浏览工具。

- 打开应用先看到地图，而不是图库首页。
- 地图上的照片缩略图是主要内容。
- 用户通过地图聚合和区域照片面板浏览照片。
- 点击照片优先交给 vivo 原生相册查看原图。
- 不重复开发手机已有的图库、缩略图和高清图片浏览能力。

设计关键词：安静、清晰、轻量、照片优先。

## 2. 设计基准与适配

- 参考画布：393dp 宽的 Android 竖屏。
- 所有尺寸使用 dp，字体使用 sp，不以截图像素硬编码。
- 适配实际屏幕宽度、系统字体缩放、状态栏、导航栏和手势区域。
- 地图铺满可用内容区域；顶部浮层和底部面板避开系统安全区域。
- 不为单一分辨率写死布局。
- 横屏不是 V1 的重点，但不得因旋转导致崩溃或状态丢失。

## 4. 地图主页

### 4.1 地图底层

- 百度地图占据整个应用内容区域。
- 地图是视觉主体，不能被大面积固定工具栏遮挡。
- 不增加底部导航栏。
- 不增加搜索、路线、人物、旅行等 V1 不需要的入口。

### 4.2 顶部品牌卡

位置：状态栏安全区域下方，左右边距 12～16dp。

从左至右：

1. 36dp 蓝灰色品牌图标，使用简洁地图定位符号。
2. 主标题「图迹」。
3. 小字副标题「MAP ALBUM」。
4. 真实照片数据状态/数量。
5. 44～48dp 圆形更多菜单按钮。

数量展示规则：

- 正式数据已就绪：显示实际有效位置照片数，例如「有位置 69,632 张」。
- 受限样本模式：明确显示「样本 8 张」或实际样本数量。
- 正在读取：显示「正在读取照片位置」。
- 身份未核验：显示「样本模式」，不得显示成全图库已就绪。
- 不允许写死测试数字或编造进度。

### 4.3 右下角地图操作

只保留一个主要悬浮操作：「适配全部照片」。

- 48dp 圆形白色按钮，轻量阴影。
- 使用 fit / maximize 类线性图标。
- 正式模式适配全部已加载的有效位置照片。
- 受限样本模式只能适配当前已选样本，并明确标识其范围。
- 这不是手机当前位置按钮，不申请设备定位权限。
- 当没有有效位置数据时禁用或隐藏，并给出简短原因。

### 4.4 更多菜单

正式模式只包含：

- 刷新照片数据
- 适配全部照片
- 隐私说明
- 关于图迹

Debug 构建额外显示：

- 身份核验
- 选择测试照片
- 清空测试样本
- 数据诊断

身份核验和样本选择不得成为正式用户界面的常驻按钮。

## 5. 地图照片标记与聚合

### 5.1 单张照片标记

- 48 × 48dp。
- 图片裁切为正方形。
- 2dp 白色描边。
- 9dp 圆角。
- 轻微阴影。
- 缩略图不可用时显示中性占位，不隐藏有效位置。

### 5.2 多张照片聚合标记

- 以照片缩略图作为封面。
- 右下角深色圆角数量角标。
- 1～999 显示实际数字，超过 999 显示 999+。
- 封面优先选择该组拍摄时间最新且缩略图可用的照片。
- 最新照片缩略图不可用时，依次选择下一张可用照片；全部不可用时使用占位图。
- 聚合组中的所有照片都必须保留，可从面板逐张浏览。

### 5.3 聚合规则

- 根据屏幕像素距离分组，不使用固定 GPS 半径。
- 初始分组网格参考 72dp。
- 初始目标标记数量不超过约 100 个，最终按实机性能调节。
- 聚合代表点使用组内屏幕坐标中心，再通过地图投影转换为标记位置。
- 代表点仅用于显示，不得修改照片原始 GPS 或写回任何数据。
- 同坐标照片必须进入同一组，不能互相覆盖。
- 缩放时自动拆分或合并。

交互：

- 点击只有一张照片的标记：直接打开该照片的原生查看器。
- 点击多张照片的聚合标记：打开底部照片面板，并切换为「此处照片」模式。
- 在聚合面板点击照片：打开原生查看器。
- 面板中提供「返回当前区域」入口。

### 5.4 地图刷新

- 地图移动期间不查询 vivo Provider。
- 地图停止后约 200ms 再刷新视野筛选和聚合。
- 取消过期的区域查询和缩略图请求。
- 尽量复用成员未变化的标记。
- 不在每次地图移动时清空并重建全部标记。
- 照片列表和地图标记必须使用同一坐标转换结果、同一视野边界。

## 6. 统一底部照片面板

底部面板是地图主页的一部分，不是独立页面，也不是 AlertDialog。

### 6.1 收起状态

高度约 112dp，不含系统导航安全区。

从上至下：

1. 居中拖动条 32 × 4dp。
2. 标题「当前地图范围」。
3. 右侧显示当前视野照片数量。
4. 横向显示最多 4 张代表性照片缩略图。

面板左右边距 0～4dp，顶部圆角 22dp，白色约 96% 不透明度，轻微阴影。

### 6.2 展开状态

高度约为可用内容高度的 68%，最大不超过 75%。

从上至下：

1. 拖动条。
2. 固定标题栏。
3. 当前区域照片数量。
4. 三列照片网格，可持续滚动。

网格：

- 图片为正方形。
- 4dp 列间距和行间距。
- 每格图片下方显示简短拍摄日期。
- 最新照片优先。
- 只加载可见项及少量预取项。
- 使用视图回收，不一次性创建全部照片视图。

### 6.3 聚合组模式

点击多照片聚合标记后，仍使用同一个底部面板：

- 标题切换为「此处照片」。
- 显示该聚合组照片数量。
- 提供轻量「返回当前区域」按钮。
- 照片网格只包含该组成员。
- 按拍摄时间倒序。
- 点击照片打开原生查看器。

不得再使用独立 AlertDialog 显示聚合组照片。

### 6.4 手势

- 拖动条和面板标题区域负责展开/收起。
- 网格滚动区域优先响应垂直滚动，不与面板拖动抢手势。
- 点击拖动条可在收起和展开间切换。
- 点击地图空白处不应误触面板。
- 地图视野变化后，当前区域模式的照片列表同步更新。
- 聚合组模式不因普通地图刷新而悄悄切换到其他照片组。

### 6.5 空状态

- 当前视野没有照片：显示「这个区域还没有带位置信息的照片」。
- 全图库没有有效 GPS：显示简洁说明，不显示空白网格。
- 数据尚未加载：显示轻量加载状态。
- 缩略图失败：显示占位图，不影响其他照片。

## 7. 原生相册与返回恢复

正常照片点击使用 Android 标准 ACTION_VIEW，传递正确的照片 URI、image/* MIME 类型和读取授权。

- 优先由 vivo 原生相册打开。
- 不依赖未公开的 vivo 私有 Intent。
- 不保证原生相册能接收图迹当前区域的照片集合并按该集合左右切换。
- 不开发独立高清照片浏览器。
- 不在正常路径使用自定义 PreviewSession / ZoomablePreview。
- 原生查看器无法打开时给出清楚提示，备用预览需单独评估。

返回图迹时必须尽量恢复：

- 地图中心和缩放级别。
- 底部面板收起/展开状态。
- 当前区域或聚合组模式。
- 照片列表滚动位置。
- 当前照片集合及其顺序。

从图迹启动外部查看器导致 Activity 进入 onStop 时，不应清空仍有效的内存位置数据和 UI 状态，也不应在正常返回时重新全量查询 Provider。

如果进程被系统真正回收，恢复时重新检查权限和数据有效性，再按数据层策略加载；不能假设进程内状态仍然存在。

## 8. 缩略图与资源管理

沿用现有 ThumbnailLoader，不建立独立缩略图库。

初始请求尺寸：

- 地图封面：144～160px。
- 网格：约 300～360px，按实际屏幕显示尺寸和密度调整。
- 收起面板预览：按实际显示尺寸请求，不请求原图。

缓存：

- 初始 LRU 上限 32MiB。
- 缓存键包含 URI、媒体版本和请求尺寸。
- 两个后台加载线程。
- 有界任务队列。
- 仅加载可见照片及少量预取项。
- 地图移动时取消过期请求。
- 正确处理 Bitmap 生命周期，不由 ImageView 回收 LRU 中仍被共享的 Bitmap。
- 不持久化图片缓存。

## 9. 状态与提示

统一以下状态的样式：

- 正在读取照片位置。
- 缩略图加载中。
- 当前区域无照片。
- 全图库无有效 GPS。
- 照片访问权限不足。
- Provider 不可用。
- 地图网络异常。
- 地图加载失败。
- 照片已删除或 URI 失效。
- 身份尚未核验。

提示使用简洁文案和中性图标，不使用阻断式弹窗，除非确实需要用户作出权限或隐私决定。

## 10. 不在本次 UI 任务中实现

- 独立照片数据库。
- 独立磁盘缩略图。
- 热力图。
- 时间轴。
- 旅行路线。
- 人物分类。
- 搜索和复杂筛选。
- 云同步。
- 照片编辑和删除。
- 多品牌适配。
- 新地图引擎。

## 11. 设计验收截图

在 X300 Pro 上提供：

1. 地图主页收起状态。
2. 当前区域照片面板展开状态。
3. 点击聚合标记后的「此处照片」状态。
4. 右上角更多菜单。
5. 当前区域无照片状态。
6. 数据加载状态。
7. 调用 vivo 原生相册及返回后的状态。

截图不得包含不必要的个人照片内容、精确坐标或私人路径；可用测试照片展示。
