# MAP-004 UI 设计规范｜图迹

> 设计基线：MAP-004 受限样本预览阶段  
> 代码基线：bbab2ca761e4613aeb69af2063b13d921386feea  
> 目标设备：vivo X300 Pro / Android  
> 本文件与同目录的 MAP-004-UI-MOCKUP.svg 配套使用，是 UI 实施的唯一视觉规范。

## 1. 产品定位

图迹是一款地图优先的个人照片浏览工具。

- 打开应用先看到地图，而不是图库首页。
- 地图上的照片缩略图是主要内容。
- 用户通过地图聚合和区域照片面板浏览照片。
- 点击照片先进入图迹自己的全屏预览页，可查看缩略图、拍摄时间并在当前照片集合内切换。
- 预览页提供「在原生相册中查看原图」，由 vivo 原生相册负责高清原图、完整缩放等能力。
- 不重复开发手机已有的图库和高清原图浏览能力。

设计关键词：安静、清晰、轻量、照片优先。

## 2. 设计基准与适配

- 参考画布：393dp 宽的 Android 竖屏。
- 所有尺寸使用 dp，字体使用 sp，不以截图像素硬编码。
- 适配实际屏幕宽度、系统字体缩放、状态栏、导航栏和手势区域。
- 地图铺满可用内容区域；顶部浮层和底部面板避开系统安全区域。
- 不为单一分辨率写死布局。
- 横屏不是 V1 的重点，但不得因旋转导致崩溃或状态丢失。

## 4. 地图主页

### 4.1 地图底层

- 百度地图占据整个应用内容区域。
- 地图是视觉主体，不能被大面积固定工具栏遮挡。
- 不增加底部导航栏。
- 不增加搜索、路线、人物、旅行等 V1 不需要的入口。

### 4.2 顶部品牌卡

位置：状态栏安全区域下方，左右边距 12～16dp。

从左至右：

1. 36dp 蓝灰色品牌图标，使用简洁地图定位符号。
2. 主标题「图迹」。
3. 小字副标题「MAP ALBUM」。
4. 真实照片数据状态/数量。
5. 44～48dp 圆形更多菜单按钮。

数量展示规则：

- 正式数据已就绪：显示实际有效位置照片数，例如「有位置 69,632 张」。
- 受限样本模式：明确显示「样本 8 张」或实际样本数量。
- 正在读取：显示「正在读取照片位置」。
- 身份未核验：显示「样本模式」，不得显示成全图库已就绪。
- 不允许写死测试数字或编造进度。

### 4.3 右下角当前位置按钮

右下角按钮的唯一职责是「定位当前位置」，不是适配全部照片。

- 48dp 圆形白色按钮，轻量阴影。
- 使用统一的定位/准星线性图标，不使用 fit / maximize 图标。
- 按钮固定在地图右下角，距右侧 16dp，位于底部照片面板顶部上方 16dp。
- 面板展开或收起时，按钮随面板高度移动，不能被面板遮挡。
- 用户点击后才触发定位权限请求及单次定位；应用启动时不自动请求当前位置。
- 成功后地图移动到当前位置，显示当前位置蓝点和定位精度圈。
- 定位完成后停止本次定位，不持续跟随，不后台定位。
- 不记录定位历史，不将当前位置写入照片 GPS 或照片位置索引。
- 定位失败、权限拒绝或系统定位关闭时显示简短说明，地图相册其他功能继续可用。

### 4.3.1 权限与百度定位 SDK

当前 Manifest 中 ACCESS_COARSE_LOCATION 和 ACCESS_FINE_LOCATION 的 tools:node="remove" 必须移除，按需声明前台定位权限：

- android.permission.ACCESS_COARSE_LOCATION
- android.permission.ACCESS_FINE_LOCATION

运行时权限只在用户点击「当前位置」时请求。兼容 Android 12+ 用户只授予大致位置的情况；有大致位置权限即可提供近似定位，不得强制要求精确位置才能继续使用地图相册。

禁止声明或申请 ACCESS_BACKGROUND_LOCATION。

百度地图底图保持 BaiduMapSDK_Map 9.0.0。按百度官方当前 Android 定位 SDK 集成文档，增加基础定位组件 com.baidu.lbsyun:BaiduMapSDK_Location:9.7.0，不要同时引入互斥的 Location_All。确认依赖兼容、AK 配置和实际构建后再落地。

按官方定位 SDK 要求：
- 用户已阅读并同意相应隐私说明后，调用 LocationClient.setAgreePrivacy(true)，并且必须在实例化 LocationClient 之前调用。
- 声明百度定位服务 com.baidu.location.f，按官方文档配置。
- 只在用户主动点击后创建/启动单次定位流程；成功、失败或超时后停止并释放定位客户端/监听。
- 国内地图坐标需与百度地图 BD09LL 对齐；定位 SDK 默认坐标类型不能想当然。读取回调中的实际坐标类型，必要时使用项目已有百度官方坐标转换能力转换一次，禁止重复转换。
- 百度官方文档说明海外定位结果可能为 WGS84，必须按回调坐标类型处理，不能把海外 WGS84 直接当作 BD09LL。
- 不请求地址、POI、海拔或方向等本功能不需要的信息。

AK 继续使用本地配置，不得提交密钥。如果定位 SDK 对 AK、包名或签名有独立要求，先核实并记录，不得把密钥硬编码进源码。

隐私说明需要明确：用户点击定位后，应用会请求前台位置权限并使用百度定位 SDK 获取当前位置；百度 SDK 按其隐私政策处理定位请求；图迹不进行后台持续定位、不建立位置历史、不上传到图迹自有服务。用户拒绝定位权限后，地图和照片浏览仍可正常使用。

### 4.4 更多菜单

正式模式只包含：

- 刷新照片数据
- 隐私说明
- 关于图迹

Debug 构建额外显示：

- 身份核验
- 选择测试照片
- 清空测试样本
- 数据诊断

身份核验和样本选择不得成为正式用户界面的常驻按钮。

## 5. 地图照片标记与聚合

### 5.1 单张照片标记

- 48 × 48dp。
- 图片裁切为正方形。
- 2dp 白色描边。
- 9dp 圆角。
- 轻微阴影。
- 缩略图不可用时显示中性占位，不隐藏有效位置。

### 5.2 多张照片聚合标记

- 以照片缩略图作为封面。
- 右下角深色圆角数量角标。
- 1～999 显示实际数字，超过 999 显示 999+。
- 封面优先选择该组拍摄时间最新且缩略图可用的照片。
- 最新照片缩略图不可用时，依次选择下一张可用照片；全部不可用时使用占位图。
- 聚合组中的所有照片都必须保留，可从面板逐张浏览。

### 5.3 聚合规则

- 根据屏幕像素距离分组，不使用固定 GPS 半径。
- 初始分组网格参考 72dp。
- 初始目标标记数量不超过约 100 个，最终按实机性能调节。
- 聚合代表点使用组内屏幕坐标中心，再通过地图投影转换为标记位置。
- 代表点仅用于显示，不得修改照片原始 GPS 或写回任何数据。
- 同坐标照片必须进入同一组，不能互相覆盖。
- 缩放时自动拆分或合并。

交互：

- 点击单张照片标记：进入图迹内部全屏预览页，照片集合仅包含该照片。
- 点击多张照片的聚合标记：打开底部照片面板，并切换为「此处照片」模式。
- 在区域面板或聚合组面板点击照片：进入图迹内部全屏预览页；左右切换范围限定为进入时的当前区域或当前聚合组。
- 面板中提供「返回当前区域」入口。

### 5.4 地图刷新

- 地图移动期间不查询 vivo Provider。
- 地图停止后约 200ms 再刷新视野筛选和聚合。
- 取消过期的区域查询和缩略图请求。
- 尽量复用成员未变化的标记。
- 不在每次地图移动时清空并重建全部标记。
- 照片列表和地图标记必须使用同一坐标转换结果、同一视野边界。

## 6. 统一底部照片面板

底部面板是地图主页的一部分，不是独立页面，也不是 AlertDialog。

### 6.1 收起状态

高度约 112dp，不含系统导航安全区。

从上至下：

1. 居中拖动条 32 × 4dp。
2. 标题「当前地图范围」。
3. 右侧显示当前视野照片数量。
4. 横向显示最多 4 张代表性照片缩略图。

面板左右边距 0～4dp，顶部圆角 22dp，白色约 96% 不透明度，轻微阴影。

### 6.2 展开状态

高度约为可用内容高度的 68%，最大不超过 75%。

从上至下：

1. 拖动条。
2. 固定标题栏。
3. 当前区域照片数量。
4. 三列照片网格，可持续滚动。

网格：

- 图片为正方形。
- 4dp 列间距和行间距。
- 每格图片下方显示简短拍摄日期。
- 最新照片优先。
- 只加载可见项及少量预取项。
- 使用视图回收，不一次性创建全部照片视图。

### 6.3 聚合组模式

点击多照片聚合标记后，仍使用同一个底部面板：

- 标题切换为「此处照片」。
- 显示该聚合组照片数量。
- 提供轻量「返回当前区域」按钮。
- 照片网格只包含该组成员。
- 按拍摄时间倒序。
- 点击照片打开原生查看器。

不得再使用独立 AlertDialog 显示聚合组照片。

### 6.4 手势

- 拖动条和面板标题区域负责展开/收起。
- 网格滚动区域优先响应垂直滚动，不与面板拖动抢手势。
- 点击拖动条可在收起和展开间切换。
- 点击照片进入图迹内部全屏预览页，不直接跳过预览。
- 点击地图空白处不应误触面板。
- 地图视野变化后，当前区域模式的照片列表同步更新。
- 聚合组模式不因普通地图刷新而悄悄切换到其他照片组。

### 6.5 空状态

- 当前视野没有照片：显示「这个区域还没有带位置信息的照片」。
- 全图库没有有效 GPS：显示简洁说明，不显示空白网格。
- 数据尚未加载：显示轻量加载状态。
- 缩略图失败：显示占位图，不影响其他照片。

## 7. 图迹内部预览页与原生相册

照片点击后必须先进入图迹自己的全屏预览页。它是 V1 正式交互的一部分，不是可选项，也不能被「直接打开原生相册」替代。

建议新增独立 PhotoPreviewActivity，使用现有 Android Views 和 ZoomablePreview 能力；也可采用等效的全屏页面实现，但不得使用 AlertDialog 冒充页面。

### 7.1 页面布局

- 全屏页面，浅色整体背景。
- 顶部工具栏高约 56dp：左侧返回，中央「照片预览」，右侧显示当前序号，例如「3 / 28」。
- 中间为照片预览区域，约占可用高度的 55%～60%；图片使用 fitCenter，完整显示，不强制裁切。
- 预览区域采用深色中性背景 #171B20，突出照片本身。
- 底部白色信息区域显示拍摄时间、可用时的主存储相对路径，以及照片切换控件。
- 底部主按钮高 48dp，文案「在原生相册中查看原图」，使用强调色 #547C91。

### 7.2 预览图片

- 通过系统缩略图接口按需读取当前照片，不直接全尺寸解码原图。
- 预览缩略图目标尺寸可按屏幕调整，初始上限参考 1080px。
- 支持双指放大和拖动查看预览细节，最大缩放参考 4 倍。
- 必须明确：放大的是系统缩略图，细节受缩略图分辨率限制；不能宣传为原图高清浏览。
- 图片加载失败时显示占位和错误说明，原生相册入口仍可使用。
- 切换照片时取消上一个图片请求，防止过期结果覆盖当前照片。

### 7.3 信息区域

- 显示拍摄时间；缺失时显示「拍摄时间未知」或明确标注系统时间回退。
- 如果 MediaStore 提供相对路径，可显示简短路径；不可用时隐藏该行。
- 不显示原始 URI、媒体 ID 或精确 GPS。
- 页面不做照片编辑、删除、分享或复杂元数据管理。

### 7.4 前后切换

- 支持左右滑动切换。
- 同时提供「上一张 / 下一张」按钮，方便明确操作。
- 中间显示当前序号，例如「3 / 28」。
- 从当前区域网格进入：只在进入时的当前区域照片集合中切换。
- 从聚合组进入：只在该聚合组照片集合中切换。
- 从单张地图标记进入：集合只有该照片，前后按钮禁用。
- 照片集合按拍摄时间倒序，并在进入预览页时形成稳定快照；预览过程中不得因地图刷新改变切换顺序。
- 首张禁用上一张，末张禁用下一张。

### 7.5 打开原图

点击「在原生相册中查看原图」后：

- 使用标准 Android ACTION_VIEW。
- 传递正确的 document URI、image/* MIME 类型及读取授权。
- 优先由 vivo 原生相册打开准确照片。
- 原生相册负责高清原图、完整缩放及其原有功能。
- 不依赖未公开的 vivo 私有 Intent。
- 不假定原生相册能接收图迹当前照片集合并按该集合左右切换。
- 若无法打开，留在图迹预览页并提示，不丢失当前预览状态。

### 7.6 返回恢复

- 预览页返回地图时恢复地图中心和缩放级别。
- 恢复底部面板收起/展开状态。
- 恢复当前区域或聚合组模式。
- 恢复照片网格滚动位置。
- 从预览页打开原生相册再返回时，先回到图迹预览页；再返回地图时恢复原状态。
- 正常页面切换不重新全量查询 Provider，不重建全部标记。
- 进程真正被系统回收时，重新核验权限和 URI 有效性，再按数据层策略恢复。

## 8. 缩略图与资源管理

沿用现有 ThumbnailLoader，不建立独立缩略图库。

初始请求尺寸：

- 地图封面：144～160px。
- 网格：约 300～360px，按实际屏幕显示尺寸和密度调整。
- 收起面板预览：按实际显示尺寸请求，不请求原图。

缓存：

- 初始 LRU 上限 32MiB。
- 缓存键包含 URI、媒体版本和请求尺寸。
- 两个后台加载线程。
- 有界任务队列。
- 仅加载可见照片及少量预取项。
- 地图移动时取消过期请求。
- 正确处理 Bitmap 生命周期，不由 ImageView 回收 LRU 中仍被共享的 Bitmap。
- 不持久化图片缓存。

## 9. 状态与提示

统一以下状态的样式：

- 正在读取照片位置。
- 缩略图加载中。
- 当前区域无照片。
- 全图库无有效 GPS。
- 照片访问权限不足。
- Provider 不可用。
- 地图网络异常。
- 地图加载失败。
- 照片已删除或 URI 失效。
- 身份尚未核验。
- 定位权限未授予/仅允许大致位置。
- 系统定位服务关闭。
- 当前定位中、定位成功、定位超时或定位失败。

提示使用简洁文案和中性图标，不使用阻断式弹窗，除非确实需要用户作出权限或隐私决定。

## 10. 不在本次 UI 任务中实现

- 独立高清原图解码/编辑体系（图迹内部轻量预览页属于必做功能）。
- 后台持续定位或位置历史。
- 独立照片数据库。
- 独立磁盘缩略图。
- 热力图。
- 时间轴。
- 旅行路线。
- 人物分类。
- 搜索和复杂筛选。
- 云同步。
- 照片编辑和删除。
- 多品牌适配。
- 新地图引擎。

## 11. 设计验收截图

在 X300 Pro 上提供：

1. 地图主页收起状态，右下角显示当前位置按钮。
2. 当前区域照片面板展开状态。
3. 点击聚合标记后的「此处照片」状态。
4. 图迹内部照片预览页（含上一张/下一张、时间信息和原图入口）。
5. 右上角更多菜单。
6. 定位权限说明/系统授权状态。
7. 定位成功后的地图当前位置蓝点及精度圈。
8. 当前区域无照片状态。
9. 数据加载状态。
10. 从预览页打开 vivo 原生相册、返回预览页，再返回地图的状态。

截图不得包含不必要的个人照片内容、精确坐标或私人路径；可用测试照片展示。
