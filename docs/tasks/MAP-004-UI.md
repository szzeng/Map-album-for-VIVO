当前实现仍存在以下验证阶段特征：

- MainActivity 顶部有选择照片、清空、身份核验等开发按钮。
- 区域照片使用固定高度 GridView。
- 聚合组使用独立 AlertDialog。
- 照片预览使用 PreviewSession / ZoomablePreview。
- 地图坐标仍有广州范围临时过滤。
- onStop 会清空样本；调用外部查看器返回时存在重新读取样本的路径。
- 当前照片读取仍是用户明确选择的 1～20 张样本。

先确认这些行为与最新源码一致，再开始修改。

## 3. 实施阶段

### 阶段 A：UI 基础组件与主页

1. 建立统一颜色、字号、圆角、间距和图标资源。
2. 地图继续全屏显示。
3. 实现顶部品牌卡、真实数据状态和更多菜单。
4. 移除正式界面的纵向开发按钮。
5. 实现右下角「适配全部照片」按钮。
6. 适配状态栏、导航栏和手势安全区域。
7. 不使用写死的广州默认地图视野。

### 阶段 B：统一底部照片面板

1. 实现收起和展开两种状态。
2. 收起状态约 112dp，显示当前范围标题、数量和最多 4 张缩略图。
3. 展开状态约可用高度 68%，最多不超过 75%。
4. 展开后显示三列惰性照片网格。
5. 点击多照片聚合标记时，切换为「此处照片」模式。
6. 提供「返回当前区域」入口。
7. 不再使用独立 AlertDialog 展示聚合照片。
8. 处理面板拖动与网格滚动手势冲突。
9. 地图视野变化时更新当前区域照片，但不打断聚合组浏览。

优先使用现有 Android Views。若项目已有合适的 BottomSheet 依赖可复用；否则实现轻量自定义面板，不为一个面板引入大型依赖。

### 阶段 C：地图标记与聚合视觉

1. 统一单张照片标记的尺寸、描边和圆角。
2. 统一聚合数量角标，超过 999 显示 999+。
3. 聚合封面优先选择最新且缩略图可用的照片。
4. 封面失败时回退下一张，全部失败时显示占位。
5. 聚合代表点使用成员屏幕坐标中心，再通过地图投影得到显示位置；不得修改照片 GPS。
6. 单张照片标记点击后直接打开原生查看器。
7. 多张聚合标记点击后打开统一底部面板。
8. 尽量复用成员不变的 Marker 和 BitmapDescriptor。
9. 地图移动期间取消过期缩略图请求，停止后约 200ms 更新。

### 阶段 D：原生相册与状态恢复

1. 正常照片点击使用标准 ACTION_VIEW。
2. 优先打开 vivo 原生相册。
3. 不依赖未公开的 vivo 私有接口。
4. 移除正常浏览流程中的 PreviewSession / ZoomablePreview。
5. 不开发独立高清图片查看器。
6. 重点修正 onStop / onResume 生命周期：
   - 从图迹启动外部图片查看器时，保留当前有效内存数据及 UI 状态。
   - 正常返回时不重新全量查询 Provider。
   - 只有进程被回收、授权变化或数据失效时，才按需恢复。
7. 恢复地图视野、面板状态、当前模式和网格滚动位置。
8. 真正进程重建时重新核验权限，不假设内存状态仍然存在。

### 阶段 E：缩略图与列表性能

1. 继续使用 ThumbnailLoader。
2. 地图缩略图请求约 144～160px。
3. 网格缩略图约 300～360px，按屏幕密度调整。
4. 继续使用 32MiB LRU、两个后台线程和有界队列作为初始策略。
5. 只加载可见项及少量预取项。
6. 避免视图复用导致旧图片闪现到新位置。
7. 缓存 Bitmap 不得被 View 任意 recycle。
8. 不保存磁盘缩略图。
9. 不因为 UI 更新重复读取 Provider。

### 阶段 F：Debug 与正式入口区分

1. 身份核验入口继续保留。
2. 选择测试照片、清空样本、诊断入口放入 Debug 菜单。
3. 正常界面不出现开发按钮。
4. 受限样本模式必须明确显示「样本模式」和真实样本数量。
5. 不显示虚构的全图库总数或加载进度。
6. 不因 UI 改造开放全图库读取。

## 4. 必须保留的安全边界

- MapDataRepository 的 IDENTITY_UNVERIFIED 状态不得删除或绕过。
- 不修改 vivo Provider 数据。
- 不扫描全部照片 EXIF。
- 不建立照片/GPS 持久化数据库。
- 不建立磁盘缩略图库。
- 不增加设备定位权限。
- 不将真实照片、精确 GPS、媒体 ID 或私人路径写入日志和测试报告。
- 广州范围过滤只有在独立完成多城市坐标验证及正式地域策略后才能移除；不得为了 UI 看起来完整而直接删除安全限制。

## 5. 验收步骤

使用当前受限样本模式，至少完成：

1. 地图主页收起状态与样图一致。
2. 底部面板可稳定展开、收起。
3. 网格可连续滚动，缩略图不会错位。
4. 点击单张照片能打开正确的系统图片查看器。
5. 点击聚合标记能打开统一底部面板。
6. 聚合组照片全部可见、可打开。
7. 点击照片后返回，地图位置、面板状态和滚动位置保持。
8. 连续打开外部查看器时不重复全量读取样本。
9. 地图快速移动时不会出现大量过期图片请求。
10. 空状态、加载状态和权限错误状态正确。
11. Debug 诊断入口可用，正式界面不显示诊断按钮。
12. Debug 构建成功，安装到 X300 Pro 实机验证。
