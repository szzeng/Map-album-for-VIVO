# MAP-007：图迹 for VIVO 品牌与机型开放

应用显示名调整为“图迹 for VIVO”，在用户确认及照片授权后允许 vivo 设备尝试图库地图；Debug 与 Release 仍分别检查构建条件，非 vivo 设备不开放。X300 Pro 有历史实机体验记录，其他机型的系统和图库接口兼容性尚未验证。

继续只读使用 vivo 图库 Provider 和 MediaStore；不扫描 EXIF 或建立照片数据库。接口查询发生异常时停止加载并提示可能不兼容；读取不到记录也可能是照片没有对应图库记录，统计中予以区分。Provider 返回的数字 ID 与 MediaStore ID 相同本身不能证明照片身份相同，因此不能保证其他机型上的照片关联正确。

验证：Debug、Release 构建通过；JVM 检查覆盖其他 vivo 型号、非 vivo、确认及构建门禁和模拟 Provider 异常。未在本次任务重新进行 X300 Pro 或其他手机的实机验证。
