# MAP-004-PREVIEW 实施与验证记录

日期：2026-11-26。GitHub `main` 检查时为 `3fea69a`，与本地提交一致；实现基于已有未提交的受限样本 UI 改动，未提交 Git。

## 实现和用户确认的调整

- 预览页使用深色照片区、悬浮顶栏及底部信息卡，支持稳定集合内的上一张、下一张、左右滑动与缩放拖动。
- 按用户后续要求，轻点照片通过标准 `ACTION_VIEW` 打开 vivo 相册，不再显示原图按钮；长按照片隐藏或恢复控件。返回箭头采用居中的线条图标。
- 地图默认不显示当前区域面板；点击多张照片聚合标记后才显示聚合面板，可关闭。单张标记仍直接进入单张预览。
- 本机对同一张照片请求 1080px 和 1440px 系统缩略图均返回 144 × 192px；另一方向的样本返回 192 × 144px。经用户明确同意，缩略图不足时通过 `ImageDecoder` 按最长边不超过 1440px 输出预览位图；不写磁盘，不扫描全图库 EXIF，原生相册仍负责原图。样本实测得到 1084 × 1440px 和 1440 × 1080px，用户反馈已清晰。
- 原有 32 MiB LRU、两个后台线程和有界队列继续使用；每张预览输出最长边上限 1440px。解码期间取消会丢弃过期结果，但平台 `ImageDecoder` 的正在进行中的原生解码不保证立即中断。真实峰值内存、大量切换和多格式性能尚未测量。
