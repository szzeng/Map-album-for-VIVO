# MAP-004.1 实验数据层

本版本为 Debug 个人设备实验；用户已完成部分手机体验检查，尚未完成全面验收。设备门槛同时检查 debuggable、vivo、V2502A、PD2502 和用户确认；主卷以 MediaStore 当前可见 ID 限定，容量超过 100,000 时停止。照片位置和预览会话仅保存在进程内。仅保存实验启用确认，不保存位置索引。Release 不显示实验入口，设备工厂也检查 debuggable。

进入地图后，在右上角菜单选择“主卷全图库实验模式”，阅读并确认提示，然后授予完整或部分照片权限。可在菜单中修改照片授权、关闭实验或复制数据诊断。定位仍需单独授予前台位置权限。地图照片暂限广州附近范围。

恢复前台和恢复预览时重新核对可见 ID；相同时复用内存位置索引，范围变化时清除旧索引并重新加载。Provider 查询仍是串行、有界且可取消；查询前后核对范围，不做固定批间等待。地图按视野查询位置索引，按需读取照片元数据和缩略图。视野很大时可能需要读取大量元数据，实际耗时和内存表现需在手机上测量。

执行 `powershell -File tests/run-jvm-tests.ps1` 可运行无需设备的聚合与数据层生命周期测试。Gradle 的 `testDebugUnitTest` 当前没有注册测试源码，不能将 NO-SOURCE 当作测试通过。JVM 测试使用 Android 替身，不能验证真实 Android 权限、vivo Provider 或地图 SDK。

## 手机体验反馈及边界

用户提供的 X300 Pro 截图显示完整照片授权、状态 READY：可见照片 79,152 张、有效位置 69,637 张；诊断中位置数据加载耗时为 479 ms。这是应用当时报告的统计，并非独立测量的端到端首次出图时间或性能基准。最初地图为空，经分批读取视野元数据等调整后，用户反馈照片可以显示、速度可接受；后续用户确认地图拖动的刷新体验可以。预览进度条已根据反馈改为拖动时切换，用户曾表示有改善；未记录逐项的首尾、快速拖动或照片内容核对结果。

此前用户已口头确认至少 30 张照片交叉核对，详见 [MAP-004 测试记录](MAP-004-device-test.md)；没有逐张清单，不能外推到所有照片。当前截图和反馈不等于全面验收。

用户随后确认本轮提出的手机验收项均无问题：部分照片授权及拒绝、恢复权限后的范围和提示；预览进入原生相册返回及关闭后重新打开图迹；当前位置的授权提示和定位结果。此处记录的是用户整体确认，未记录每一步的操作细节、具体授权组合或独立测量结果。

仍未单独测量或验证：完整加载的端到端耗时与内存峰值；大图库中每张照片的身份及位置准确性；定位精度、海外定位和坐标结果。坐标系验证和广州范围外照片支持仍属于 MAP-004.3。


## 全球地图实验扩展

根据用户后续要求，已移除广州范围限制。跨日期变更线的视野使用环绕经度筛选；超宽视野采用保守的全球经度范围。超过一万点的视野以原始类型数组生成聚合概览，封面和用户选中的聚合按需读取；单个聚合超过一万张会要求放大，极端同位置密集照片在最大缩放级别可能无法继续展开，不做静默截断。

坐标仍是假设 Provider 输出 WGS84：代码以粗略矩形判断国内附近并调用百度 GPS 转 BD09LL，其他地区原样输入 WGS84。该矩形并非国界，附近的国外照片可能误用国内转换，中国极南地区也可能被误判；Provider 坐标契约和全球位置准确性均未经实机核验。百度官方资料说明国内（含港澳台）使用 BD09LL、海外使用 WGS84；境外底图服务为付费业务，按请求网格计费，见[坐标转换说明](https://lbsyun.baidu.com/docs/android?title=androidsdk/guide/tool/coordinate)和[境外地图服务说明](https://lbsyun.baidu.com/docs/android?title=androidsdk/guide/create-map/showmap/abroad)。

全球范围、跨日期变更线、海外地图与坐标准确性、极大聚合及实际性能均未做手机验收；原有身份与授权安全门槛不变。

用户后续反馈韩国、香港照片位置正确；对岘港照片，修正单张标记的屏幕投影取整后，用户反馈位置已正确。该反馈仅覆盖用户观察的照片，不证明所有海外照片的坐标系或边界判断正确。
