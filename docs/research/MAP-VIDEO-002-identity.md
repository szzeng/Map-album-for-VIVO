# MAP-VIDEO-002 身份核验记录

2026-11-27，在 X300 Pro / V2502A 上通过 Debug 验证页读取当前授权的主卷最近样本，仅比较内存中的路径，不记录路径、ID 或坐标。

- 相机目录最近 20 条视频：Provider 同 ID 记录 `media_type` 均为 3，MediaStore 与 Provider 路径均逐字一致。
- 所有目录最近 20 条视频：同样均为类型 3、路径一致；这组样本可能与相机目录样本重叠。
- 相机目录最近 20 条照片：Provider 同 ID 记录 `media_type` 均为 1，17 条路径逐字一致，3 条路径不同但文件名一致。路径差异的原因和这些记录的身份尚未确认，不能据此判断现有照片定位错误。
- 这是有限的设备样本，不建立其他来源、卷或系统版本上的 Provider 身份契约。照片 GPS 读取逻辑未修改。用户表示无需再核验坐标位置，视频沿用照片坐标规则。

路径与类型吻合支持样本关联，但不能单凭样本推出所有记录都可靠。实现对每条视频检查类型为 3、路径逐字一致；缺失或不匹配的记录不会进入地图，因此路径别名也可能导致视频不显示。用户同意先继续实现，并确认视频沿用照片坐标规则。

## 当前验证

- Debug 和 Release 编译通过，原有 JVM 检查及媒体身份检查通过。
- X300 Pro Debug 版观察到混合面板分别计数、视频标记播放图标、照片预览与面板返回；视频可调用 vivo 默认播放器。撤销完整视频权限后，若没有可见视频，回退到照片模式。系统仍可能保留部分媒体授权。
- 视频缩略图沿用系统 `loadThumbnail`；索引时读取修改时间供内存缓存使用，避免逐标记排队查询。少量调试样本的系统调用耗时不足以证明所有场景的性能。
- 尚未完成完整的部分授权重选、拒绝权限、混合聚合逐项计数、播放器返回后位置和性能等验收；其他设备及非相机来源的视频身份仍需进一步验证。
