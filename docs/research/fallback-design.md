# MAP-001 V2 · 一次 EXIF 建索引与增量同步

## 推荐架构

`MediaStore 可见元数据目录 → 持久 EXIF 待办 → 应用私有 SQLite → 地图视口查询`。先以原生 Android 实现数据层。地图用本地索引返回视口内点或聚合，点击后再按授权 URI 加载缩略图。系统 MediaStore 权限决定可用照片范围，位置授权决定是否提取、显示和保留坐标。

目录用 `(volume, media_id)` 标识行，记录 `media_store_version`、行 generation、拍摄时间及来源、MIME 类型、大小和修改时间。URI 从当前卷和 ID 派生。GPS 用检查状态区分 `pending`、`has_gps`、`no_gps`、`unsupported`、`permission_required` 和 `retryable`。空坐标需要明确状态，解析失败可退避重试。持久化记录位置但不保存原图、私有绝对文件路径或 EXIF 全文。位置表仅在照片仍可见且当前会话具有授权时对地图开放。

## 同步和一致性

1. **首次导入**。页读当前可见图片目录，优先近期或用户指定集合。只对已授权、尚无当前位置结果的条目打开原始文件并解析所需元数据。单 worker、小批事务、进度可见、可暂停续跑。GPS 缺失的成功结果同样缓存。位置权限不在时等待授权，避免把受限 EXIF 当作永久无 GPS。
2. **正常增量**。按卷读取 version 和 generation 上界 `hi`，把 `lo < GENERATION_MODIFIED <= hi` 的可见行按 `(GENERATION_MODIFIED, _ID)` 分页。`GENERATION_ADDED` 辅助识别新行及 ID 重新出现。持久化更新目录及必要解析待办后才提交 `hi`，并复核 version 和授权状态，异常时重做该窗口。EXIF 工作者在结果入库前复核行标识、权限和当前 generation，避免覆盖较新的编辑或已经不可见的照片。
3. **按需重解析**。新增行与出现潜在文件内容变化的修改行入队。`size`、`DATE_MODIFIED`、MIME 等可用于优先级，字段相同仍可能发生原位改写。无法可靠确认仅为目录元数据变化时，重解析该修改行。去重键包含卷、版本、ID 和行代次。
4. **删除与不可见**。单项通知可触发原 URI 复核。集合通知或低频任务做可见 ID 对账。一次分页未完成、存储卷暂时卸载或查询失败时保留游标及待办，隐藏失联卷记录，待重新核对后再清理。全量权限且卷在线、可见快照完成后才能将缺失行当成已移除。权限缩小导致的不可见同样从地图与本地位置索引清除，但不记为真实文件删除。
5. **权限与版本变化**。前台恢复、选取回调和重新授权时复核权限并检查可见 ID，包括部分选取内容变化。位置或读权限撤销时先使对应地图数据不可见，清理失去授权的坐标。版本改变时重建受影响卷的目录和游标，只有在可证明媒体身份和文件内容未变时才复用旧 EXIF 结果，无法确认时局部重解析。API 29 及更早如果支持，以元数据对账兜底，无法提供同级 generation 保证。

## 成本评估

Windows 使用 10,000 张约 40 KB 的合成 JPEG，20% 含合成 GPS，单读取线程，每 256 行一次提交，包含首次文件打开和 GPS 解析，文件刚生成，系统缓存偏热。

| 工作量 | 实测墙钟 | 实测进程 CPU | 解析次数 / 解析器逻辑读取 |
| --- | ---: | ---: | --- |
| 首次 10,000 张 | 1.2994 秒 | 1.2656 秒 | 10,000 次 / 3,908,000 B |
| 同代 10,000 行对账 | 0.5234 秒 | 0.5156 秒 | 0 次 / 0 B |
| 100 项标记为修改 | 0.0163 秒 | 0.0156 秒 | 100 次 / 39,080 B |

最小 SQLite 表为 147,456 B。实际方案会增加目录、队列、空间索引及 WAL 开销。逻辑读取量计量 Pillow 消费的字节，不代表硬件 I/O。测试不含 Android IPC、冷盘、HEIC/RAW、高延迟 URI、真实图库分布及功耗。

首次成本约为 `N × 每张打开和元数据解析耗时 + 目录与事务`。作为容量预算，假定手机单张平均 2–15 ms，则 10,000 张约 20–150 秒，50,000 张约 100–750 秒，均还需计入目录、事务和调度。这些是假设区间。例行同步解析工作量与变化照片数成正比，100 张的相同假设约 0.2–1.5 秒。全量可见 ID 对账仍随行数增长，只查询元数据。

下一阶段可在授权的隔离测试设备上，按 JPEG、HEIC、RAW 和异常文件分别测量耗时 P50/P95、冷暖启动、逻辑及设备 I/O、电量、进程内存、崩溃续跑、零变化原图打开数和部分授权切换。目标机未测图库首次索引时间与资源消耗。
