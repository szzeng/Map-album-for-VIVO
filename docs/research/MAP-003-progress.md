# MAP-003 地图相册样本验证（完成样本，保留限制）

2026-11-24；设备 vivo X300 Pro / V2502A。独立 Android 工程为 `x300pro-map/`，未修改 MAP-002 的 `MapDataRepository.forDevice` 身份门槛。验证期间未提交 GitHub。

## 地图

MapLibre Native Android 13.7.1；天地图 HTTPS WMTS `vec_w` 和 `cva_w` 栅格叠加。用户手动配置 Key 到手机应用私有文件，Key 不记录在本报告。已在手机看到底图与中文注记，用户确认地图画面正常。Key 的账户配额、长期限制以及服务对应审图号仍待天地图控制台和服务方进一步核验；不将一次可显示视为配额和合规验收。

## 照片和位置

系统文档选择器获取用户选定 URI；使用 `MediaStore.getMediaUri` 转换，逐项读取 MediaStore `_id` 和 `volume_name`，仅允许明确的主卷，并通过复用 MAP-002 `PrimaryPhotoSource.appendBatch` 对选定 ID 查询 vivo Provider。复核返回 ID、坐标有效性及媒体可见性。仅请求选定条目，数据在内存；不申请全图库权限，不重扫 EXIF，不建照片/GPS 数据库。Provider 与 MediaStore 间身份和授权检查不是原子事务，厂商跨版本身份契约未验证；该入口仅用于用户明确选中的受限样本。

初版对系统返回的汇总卷 URI 直接拒绝，用户的三张照片均显示“卷未确认”。后续通过选中项目的 `volume_name` 显式确认主卷，再次选择后用户反馈可以显示，并曾确认照片标记与实际地点基本吻合；随后另一轮选择三张时用户观察到地图上只看到两个标记，可能存在位置重叠。新增附近照片列表后，用户重选三张并确认能分别打开，表示没有问题。未保存照片、GPS、路径或具体地点作为测试证据；无 GPS 与无法关联的最终具体数量未记录；用户确认三张样本可分别打开。该样本验证不证明所有照片或其他设备的身份关系。

未施加坐标转换：vivo 原始经纬度直接作为 MapLibre 经纬度显示，MapLibre 内部负责 Web Mercator 投影。已见样本的用户对照支持所见位置基本吻合，不足以确定 vivo Provider 的坐标基准或建立跨区域 WGS84/GCJ-02 结论。不得使用固定偏移。
