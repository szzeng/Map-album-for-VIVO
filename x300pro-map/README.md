# 图迹 / Map Album

正式 Android 应用身份：`io.github.szzeng.mapalbum`（applicationId 和 namespace）；工程目录为 `x300pro-map/`，GitHub 仓库为 `szzeng/x300pro-map`。

当前是受限照片样本 MVP：使用百度 Android 地图 SDK 9.0.0 普通地图，用户明确选择 1～20 张主卷照片，照片和位置仅保存在内存中，不是完整相册。当前样本验证仅支持广州附近照片；非该范围的照片不会自动定位或显示标记。MAP-002 的 `IDENTITY_UNVERIFIED` 设备身份门槛不变。

三张广州附近样本由用户对照实地位置，WGS84 转 BD09LL 最吻合。本版本使用百度官方离线坐标转换工具处理显示位置，原始 GPS 不变；vivo Provider 的普遍坐标基准和其他地区照片尚未验证，地图显示结果仍需用户核验。

## MAP-004 身份核验入口

地图页的“身份核验”是只读诊断工具：从系统文件选择器明确选择 1～40 张照片，逐张查看主卷媒体 ID、拍摄时间、系统缩略图和 vivo Provider 原始坐标，并通过标准 `ACTION_VIEW` 打开所选照片。资料仅存在进程内，不生成核验记录或修改图库。原始坐标系尚未普遍验证，不能仅凭坐标数字接近就认定转换已通过。诊断显示“Provider 无对应记录”与“坐标为空”是不同情况。

完整的 MAP-004.1 需要至少 30 张不同来源、时间、位置以及无 GPS 的真实照片，由使用者在原生相册中对照；还需要授权变化、自然删除与重启后等验证。工具本身不会验证照片身份，也不解除 `IDENTITY_UNVERIFIED`。操作步骤、当前阻塞及实机记录见 [MAP-004 测试记录](../docs/research/MAP-004-device-test.md)。这是诊断 APK，尚不是正式相册 V1。

受限样本地图采用地图优先界面：默认隐藏照片面板，点击多照片聚合标记后显示该组照片，按时间倒序排列；点击单张标记或组内照片先进入图迹预览页，可在进入时的照片集合内切换，轻点照片通过标准 `ACTION_VIEW` 打开原图，长按照片显示或隐藏预览控件。正常返回时保留进程内样本、地图和面板状态，不重新读取 Provider。Activity 重建时，重新检查所选 URI 的访问并恢复样本；身份核验状态不会因此改变。Debug 菜单保留身份核验、选择和清空测试样本及仅显示汇总数量的数据诊断。

位置读取阶段不加载图片；地图封面、可见网格及预览按需读取系统缩略图。用户同意后，当系统返回的预览缩略图过小时，预览页对所选照片执行最长边不超过 1440px 的内存降采样，不建立磁盘缩略图库，也不解码全尺寸位图。缩略图加载器使用最多 32 MiB 的内存缓存、两个后台任务和有界队列。地图视野仅在进程内供页面恢复，不持久化当前位置或样本位置索引。上述流程仍限于最多 20 张手动选择的样本，不能代表大图库性能或全图库数据层已验收。

右下角按钮由用户主动触发单次前台定位，不自动定位或后台跟踪。定位使用百度基础定位 SDK 9.7.0，与地图 SDK 共用本地 AK；定位服务需在百度控制台为该 AK 启用，包名及签名须匹配。首次使用前须阅读并同意地图及定位隐私说明。经用户确认，增加普通权限 `ACCESS_WIFI_STATE` 供 SDK 辅助定位；不申请后台定位权限。X300 Pro 已完成一次成功定位并显示蓝点；精度圈、大致位置、授权拒绝和失败处理仍需实机验收。

## 本地构建

使用 Gradle 8.6、Android Gradle Plugin 8.4.2、compileSdk 34。地图组件、坐标工具及基础定位使用百度 Maven 依赖 `BaiduMapSDK_Map:9.0.0`、`BaiduMapSDK_Util:9.0.0` 和 `BaiduMapSDK_Location:9.7.0`；复用 `../map002-provider-probe/src` 中原有数据读取和筛选源文件。

在 Git 忽略的 `local.properties` 中设置 Android SDK 路径及 `baidu.map.ak`，缺少 AK 时构建会明确报错。AK 会被打入 APK，APK 不是保密存储；请配置百度控制台的包名和签名限制，不要将本地配置或签名密钥提交 Git。首次打开地图须阅读并同意百度隐私说明；SDK 初始化发生在同意后。

国内地图非商业服务及境外底图计费边界、实机结果和未验证项见 `../docs/research/MAP-003B-baidu-progress.md`。旧 MapLibre / 天地图实现可从 Git 历史基线 `754bb2f` 找回。
